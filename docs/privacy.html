Tiger Type

Privacy Policy

Last updated November 16, 2026

Short version: Tiger Type sends the text you're typing to a Tiger Type server run by your school (or by you) so it can check spelling and grammar. That server checks the text and sends back suggestions. It doesn't save your writing, doesn't use AI, and doesn't share anything with anyone else. Tiger Type has no ads, no tracking, and no analytics.

What Tiger Type is

Tiger Type is a spelling and grammar checker made by Mary Chickering, a student at Greenwich Country Day School. It's made up of a Chrome extension, an optional Google Docs add-on, and a Tiger Type server. Checking uses LanguageTool's open-source grammar rules. No AI or machine learning models are used.

What data Tiger Type handles

  • Text you type in text boxes on websites where Tiger Type is turned on. When you pause typing, that text is sent to the Tiger Type server to be checked.
  • The text of a Google Doc, only when you use Tiger Type in that doc (the "Check this doc" button or the Tiger Type add-on).
  • Settings stored in your browser: the server address and the sites where you've turned Tiger Type off. These stay in your browser.
  • Issue counts for open tabs (like "2 spelling, 1 grammar"), kept in your browser's memory so the popup can show them. They're cleared when you close the tab.

Tiger Type doesn't collect your name, email address, browsing history, location, or any other personal information.

Where your text goes

Text is sent only to the Tiger Type server set in the extension. At school, that's a server controlled by Greenwich Country Day School. If you installed the Tiger Type server on your own computer, it's that computer (localhost). Text isn't sent to the makers of Tiger Type, to LanguageTool's company, or to any other third party.

What the server does with it

  • Checks it against grammar and spelling rules and sends back the issues it finds.
  • Doesn't save the text, write it to logs, or keep it after the check is done.
  • Saves only the admin settings (on or off, which categories are checked, the school dictionary, blocked sites). None of those settings contain student writing.

Google Docs

When you click "Check this doc," the extension downloads the doc as plain text using your own Google sign-in, the same as File → Download → Plain text, and checks it. The Tiger Type add-on reads your doc's text so it can check it. If you leave highlighting on, it adds highlight colors to mistakes and replaces text when you click a suggestion. It only removes highlights in Tiger Type's own colors, never ones you added. Nothing is saved outside your doc.

What Tiger Type never does

  • Sell, rent, or share your data
  • Use your data for ads, profiling, or anything other than checking your writing
  • Use your writing to train AI
  • Run on sites your school has blocked, or on sites where you've turned it off

School controls

School administrators can turn Tiger Type off for everyone, choose which kinds of mistakes are checked, add words to a school dictionary, and block sites. They can't see what students write.
